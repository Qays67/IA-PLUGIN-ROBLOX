Étape 1

Installer le plugin

Une seule fois, 30 secondes. Ensuite il s'ouvre avec Roblox Studio.

1

Télécharger

Récupère le fichier XozHubAI.rbxmx.

XozHubAI.rbxmx
2

Importer dans Studio

Ouvre Roblox Studio, puis dans l'Explorer : clic droit → Insert from File… → choisis le fichier.

3

Enregistrer comme plugin

Clic droit sur le script XozHubAI → Save as Local Plugin. Un bouton XozHub AI apparaît dans la barre d'outils.

Méthode manuelle (copier le code source)

Crée un Script dans Studio, colle le contenu de XozHubAI.plugin.lua, puis clic droit → Save as Local Plugin.

Le bouton n'apparaît pas dans Studio

Va dans Plugins → Manage Plugins et vérifie que XozHub AI est activé. En cas de doute, relance Roblox Studio.

Étape 2

Connecter le plugin au site

Le site affiche un code. Tu le tapes une fois dans le plugin. C'est lié.

Code d'appairage

En attente

Clique sur le bouton : un code apparaît ici. Ouvre le plugin dans Roblox Studio, colle-le dans le champ Code et valide.

Le flux, en clair

  1. Le site fabrique un code 6 caractères, unique, lié à ta session.
  2. Le plugin envoie ce code Le serveur reconnaît la session et appaire les deux côtés.
  3. Tu discutes d'un côté ou de l'autre Le site et le panneau Studio partagent la même conversation.
  4. L'IA renvoie du code Bouton « Insérer » dans le plugin → c'est dans ton jeu.
Tout tourne sur ta machine. Le site, le serveur et le plugin communiquent en local.
